# The Bureau of Questionable Knowledge — Host Quick Reference

## Before the assessment

1. Choose **First Assessment** for new candidates or **Recommended Multiplayer** for a ready-balanced two-to-four-player match.
2. Open **Customise assessment** only when the group wants to choose match length, question familiarity, departments, scoring pace, timer or Office Politics separately.
3. Match length controls the number of departments. Question familiarity controls how recognisable or obscure the questions are; it never changes match length.
4. Leave the timer off and keep Guided mode on until the department controls feel familiar.
5. Choose **Relaxed** scoring pace for unhurried reading, **Standard** for a gentle continuous time influence, or **Rapid** for the full original decay. This setting is separate from the countdown timer and never puts scores into fixed bands.

## During play

- The highlighted candidate acts unless the screen says the round is shared or sealed.
- When **Confidential Handover** fills the screen, pass the device to the named candidate. Everyone else looks away; the recipient confirms their name before the private controls appear.
- Complete each department's three-step control demonstration the first time it appears. Use **Replay** whenever the group needs a reminder.
- Expand the example and host cue only when extra explanation is useful.
- Unknown free-text answers pause for an Accept, Edit or Reject ruling. Accept reasonable factual variants, not merely related answers.
- The question-mark button opens pause, restart and skip controls.
- Never refresh deliberately, but if it happens choose **Resume game**; progress is filed locally.

## Office Politics

- **Back** predicts the active candidate will meet the displayed standard.
- **Object** predicts they will miss it.
- **Abstain** makes no prediction.
- Light mode stops there. Standard mode adds optional Influence-funded motions.

## If play becomes blocked

Open the host dossier. Restart the current attempt first. Skip for zero only when the challenge cannot be completed. Both actions ask for confirmation.

## Windows edition

- Press **F11** or use the header fullscreen button to enter or leave fullscreen.
- Closing the window during an assessment asks for confirmation and retains the latest filed recovery state.
- If the display process fails, choose **Reload saved assessment**. Do not start again unless the resume file is genuinely unwanted.
- Use **Export recovery file** on the opening screen before moving a browser game to another machine. In the Windows edition, choose **Import web save** and select that JSON file.

## Getting help

- On the Windows opening screen, expand **Recovery and Windows maintenance** and choose **Export support bundle**. This contains technical versions, update state and a short crash-log tail, but excludes candidate names and recovery records.
- Include the product version, Windows version, portable or installed edition and the last completed action when reporting a problem.
- Do not send a recovery file unless support specifically requests it; it can contain candidate names and match history.
- The internal release candidate has no public support address. Commercial distribution remains blocked until the accountable publisher supplies the monitored route recorded in `SUPPORT.md`.
